# 🎛️ Vertical Radio Menu

Componente de menu vertical desenvolvido com **HTML e CSS**, utilizando radio buttons estilizados e um indicador visual animado que acompanha a opção selecionada, criando uma experiência moderna e fluida sem uso de JavaScript.

---

## 🎯 Objetivo do Projeto

Este projeto tem como objetivo explorar animações, estados e interações visuais utilizando apenas CSS, servindo como estudo de UI/UX e como base para componentes reutilizáveis em interfaces web.

---

## 🧩 Funcionalidades

🎚️ Menu vertical com seleção por radio button  
✨ Destaque visual na opção ativa  
🟡 Indicador (glider) animado com efeito neon  
🎞️ Transições suaves e design minimalista   

---

## 🛠️ Tecnologias Utilizadas

* **HTML**  
* **CSS**
